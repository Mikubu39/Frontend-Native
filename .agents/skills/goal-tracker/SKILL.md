# Goal Tracker Skill

## Responsibility

Constantly align work with the overarching mission described in the project files.

## Guidelines

Before taking non-trivial actions, check:

- "How does this move us toward a fast, stable, accessible React Native application?"
- "Is this within the current session goal, or is it scope creep?"
- "Is this a nice-to-have refactor or a necessary change?"

## When to Surface Alignment

Explicitly mention mission alignment when:

- Proposing a larger refactor or new library.
- Suggesting a different approach than the user initially asked for.
- Deciding between two viable implementations.
